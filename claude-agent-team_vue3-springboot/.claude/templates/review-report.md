# Code Review 报告模板（Review Report）

> 由 reviewer-agent 在完成审查后输出。  
> 每条意见必须有明确的修改建议，不能只指出问题。

---

## Review 报告

**报告ID**：REVIEW-{TASK-ID}
**关联任务**：{TASK-ID}
**Review 时间**：{YYYY-MM-DD HH:mm}
**审查范围**：{文件列表或模块名}
**审查类型**：新功能 / Bug修复 / 重构 / 安全加固

---

| 审查维度 | 问题数 |
