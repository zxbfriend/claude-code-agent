# Bug Fix Workflow

Use this workflow for defects, crashes, incorrect behavior, and production-like failures.

## Goal

Diagnose the root cause, implement the minimum safe fix, validate the fix, and document residual risk.

## Flow

1. Reproduce or characterize the issue.
2. Identify affected layers and likely root cause.
3. Create tasks for diagnosis, fix, validation, and review.
4. Start the first runnable task immediately.
5. Validate the fix with focused regression coverage.
6. Produce a delivery report.

## Required Outputs

- Root cause summary
- Code fix
- Test evidence
- Review report
