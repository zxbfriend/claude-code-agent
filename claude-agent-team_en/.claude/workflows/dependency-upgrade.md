# Dependency Upgrade Workflow

Use this workflow for library, framework, runtime, or build-tool upgrades.

## Goal

Upgrade dependencies safely, preserve compatibility, and surface breaking changes early.

## Flow

1. Identify target versions and upgrade scope.
2. Review release notes and breaking changes.
3. Create tasks for code adaptation, config updates, testing, and review.
4. Start the first runnable task immediately.
5. Run targeted validation for affected integration points.
6. Document any follow-up work.

## Extra Checks

- API or config changes
- Migration notes
- Security improvements or regressions
