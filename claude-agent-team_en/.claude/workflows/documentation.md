# Documentation Workflow

Use this workflow for README updates, API docs, runbooks, onboarding notes, and release notes.

## Goal

Produce accurate documentation that matches the current system behavior and intended audience.

## Flow

1. Determine the target audience and document type.
2. Gather source-of-truth inputs from code, configs, and tests.
3. Create documentation tasks with ownership.
4. Start the first runnable task immediately.
5. Review for correctness, clarity, and completeness.
6. Deliver the updated documentation.
