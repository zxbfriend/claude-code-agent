# Change Request Workflow

Use this workflow when an existing feature must be adjusted without being a net-new feature.

## Goal

Apply the requested change with the smallest coherent scope while preserving existing behavior.

## Flow

1. Clarify what changes and what must remain unchanged.
2. Assess impact across backend, frontend, database, and docs.
3. Create tasks with explicit ownership and dependencies.
4. Start execution immediately unless blocked.
5. Validate changed paths and key regressions.
6. Review and summarize delivery.
