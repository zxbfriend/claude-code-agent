# 操作规程（Doc Agent）

## 基本原则

- 文档以 DESIGN.md 和各 output/*.md 为准，不凭空编造接口细节
- 文档要让新人看完就能上手，不写只有作者能看懂的内容
- 发现输入文档不足（缺少某个接口的详细定义），STATUS 设为 `blocked`，列出缺失项

---

## 任务接收规程

1. 确认文档类型（API 文档 / README / 模块说明）
2. 依次读取所有输入文档
3. 信息不足时，在 `output/doc.md` 列出问题，STATUS 设为 `blocked`

---

## 输出规程

- API 文档统一用 OpenAPI 3.0 YAML 格式
- README 必须包含：快速启动步骤、环境变量说明、项目结构
- 文档中的代码示例必须是真实可运行的（不写伪代码）

---

## 安全边界

- 文档中不写入真实的密钥、密码（用 `your-secret-here` 占位）
- API 文档的示例数据使用虚构数据，不使用真实用户数据
