# shared/README.md

这是 `dev-agents` 的统一共享入口。

## 入口说明

1. 协议入口：`../HANDOFF.md`
2. 模板目录入口：`../templates/README.md`
3. 模板总表：`./agent-template-map.md`
4. 需求文档目录：`../docs/README.md`
5. 报告目录：`../reports/README.md`
6. 交接目录：`../handoff/README.md`

## 推荐使用顺序

1. 先看 `HANDOFF.md`
2. 再看 `agent-template-map.md`
3. 然后按 `templates/` 选择模板
4. 最后在 `docs/`、`reports/`、`handoff/` 中落实例文件
